# Night and thermal search · standard 0.7.0 / XR 0.4.0

The existing instructor section contains a collapsed Gece ve arama eğitimi disclosure. Day is the unchanged default. Evening/night transitions are smooth; world illumination, sky, reflections and visible terrain are dimmed together. The sky is illustrative, not an astronomical simulation. Navigation LEDs, twelve landing markers and one short-range shadowless landing light are added. Selected heritage stone surfaces receive an illustrative warm facade contribution. Existing geometry, water simulation, UI columns and top-right map remain intact.

Thermal is applied to world materials only in the drone view, never to the DOM map, telemetry or the separate XR room. White-hot and black-hot use synthetic surface classes, warm person materials, coarse surface variation and distance/haze contrast reduction. This is not actual thermography, calibrated radiometry or measured Istanbul temperature data. No added render target, full-scene extra render pass, remote assets or paid service. Underlying shader/material hooks and terrain displacement are retained. Reflections still use the existing precomputed environment approximation.

Camera tilt is 10–85 degrees; default preserves the original camera direction. Prepare search replaces the current unsaved route with six sweep waypoints at 80 m. It selects night, white-hot and 55-degree tilt. The person is placed on clear dry ground within the existing training boundary; if no suitable point is loaded the preparation fails with a visible message. The target position is not marked on the map. Detection requires three continuous simulation seconds within the central 35% half-width/height of the camera, range 8–240 m, thermal enabled, live link and unpaused active flight. Terrain/obstacle checks use the existing world collision representation. Thin objects omitted by that representation are not guaranteed occluders. The thresholds are teaching choices, not a real sensor specification.

Detection is logged with coordinates and simulation time. Safe return is distinct from detection in the final report and CSV. The existing 100-point flight-safety score is unchanged. Reset retains the prepared search route but clears acquisition; selecting another example/saved route or editing cancels the search. Reload starts ordinary daytime. In Quest choose the lesson, time and sensor before VR; the established station controls and map remain unchanged. The person is deliberately a simple procedural training figure.
